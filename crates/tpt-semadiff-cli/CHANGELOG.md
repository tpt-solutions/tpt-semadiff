# Changelog

All notable changes to `tpt-semadiff-cli` are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

Initial implementation, not yet released.

### Added

- The `semadiff OLD NEW` command compares two files and prints a boxed per-function summary.
- `semadiff OLD_DIR NEW_DIR` compares the supported files of two directory trees, paired by
  relative path.
- `semadiff --rev REV`, `--rev A..B` and `--rev A...B` compare the files git reports as
  changed, following renames.
- Git's seven-argument external-diff form is accepted, and always exits `0`.
- `--out text`, `unified`, `json` and `markdown`. Markdown renders a pull request comment.
- `--engine chawathe` (default) and `zhang-shasha`.
- `--ignore-formatting` makes comment-only edits report zero changes.
- `--color auto|always|never`, with `NO_COLOR` honoured.
- `--summary rules|llm|off`. Rules are on by default when stdout is a terminal. The `llm`
  choice uses the Anthropic API when `ANTHROPIC_API_KEY` is set, and falls back to rules.
- CI gates: `--max-functions N` and `--fail-on-unparseable`.
- `--tui` opens the interactive viewer for one file pair.
- `semadiff git-setup` writes the difftool config, with `--global` (default), `--local`,
  `--external` and `--uninstall`. It is idempotent.
- `semadiff completions <shell>` prints a shell completion script.
- `semadiff doctor` checks git, the difftool config, the API key and each built-in grammar.
- Installers for macOS, Linux and Windows, generated by cargo-dist.
