# Changelog

## Unreleased

## 0.1.0 - 2026-11-03

Initial public release.

- Parsing with tree-sitter for Rust, Python, JavaScript, TypeScript (`.ts`, `.mts`, `.cts`),
  TSX (`.tsx`) and Go.
- `semadiff OLD_DIR NEW_DIR` compares the supported files of two directory trees. It honours
  `.gitignore` and skips generated, minified, vendored and lock files by default.
- `semadiff --rev REV`, `--rev A..B` and `--rev A...B` compare the files git reports as changed.
- `semadiff git-setup` writes the difftool config, with `--external`, `--driver`, `--alias`,
  `--local` and `--uninstall`. It is idempotent.
- `semadiff completions <shell>` prints a completion script. `semadiff man` prints the man page.
- `semadiff init` writes a commented `.semadiff.toml`. The file sets the engine, the summary,
  excludes, the CI gates and extension mappings. Flags override it.
- `--lang NAME` reads every file as one language. Scripts without an extension are recognized by
  their `#!` line.
- `--exclude GLOB` leaves paths out of directory and revision mode.
- `--quiet`, `--stat` and `--name-only` print brief forms for scripts and hooks.
- `semadiff doctor` checks git, the difftool config, the API key and the grammars.
- `--out markdown` renders a pull request comment.
- CI gates: `--max-functions N` and `--fail-on-unparseable`.
- `--out unified` names the function of each hunk, as `git diff` does.
- Closures, lambdas and arrow functions are grouped under their binding name, or under the
  enclosing named function when unbound.
- `--summary rules` is on by default when stdout is a terminal; `--summary off` turns it off.
  `--summary llm` says in the output why it fell back to the rules.
- The LLM summarizer reads `SEMADIFF_LLM_MODEL`, `SEMADIFF_LLM_MAX_TOKENS` and
  `SEMADIFF_LLM_SYSTEM`. It is behind the `llm` feature of `tpt-semadiff-core`, on in the CLI.
- `--ignore-formatting` ignores comments, Python docstrings, redundant parentheses and trailing
  commas. See `docs/usage.md`.
- JSON output carries `schema_version`, and `docs/semadiff.schema.json` describes it.
- Multi-file runs diff in parallel and keep their order. `--engine zhang-shasha` warns on large
  inputs.
- Installers for macOS, Linux and Windows, generated by cargo-dist.
- Trivia normalization with a reconstructable segment list.
- Chawathe/GumTree-style matcher (default) and a Zhang-Shasha engine.
- Semantic report grouped by function; boxed text, unified and JSON output.
- Interactive TUI viewer.
- Git difftool and external-diff invocation.
- Rule-based summaries (rename, import reorder, extract function, inline variable), plus
  an optional LLM summarizer with offline fallback.
